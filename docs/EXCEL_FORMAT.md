# Формат бюджета для импорта в Life Hub

Файл `Budget_Oct-Dec_2026.xlsx`. Приложение читает его строго по этому описанию: если обязательной колонки нет или значение не из списка, импорт останавливается и называет лист, колонку и номер строки. Догадок по названиям нет.

## Общие правила

- **Заголовки** — в строке 1, точно как здесь написано. Данные — со строки 2. Лишние колонки (формулы, «Месяц», «Сумма со знаком», «На счетах после строки») можно оставлять: импорт их не читает.
- **Без объединённых ячеек и промежуточных итогов внутри таблицы.** Итоги и сноски — на отдельном листе или ниже таблицы после пустой строки.
- **Даты** — настоящие даты Excel, не текст («13.10.2026», не «Fr 13.10»).
- **Суммы** — положительные числа без «€», до двух знаков после запятой. Направление задаёт колонка «Знак» (в «Статьях») или «Направление» (в «Долгах»).
- **Значения из списков** пишутся точно как в списке (регистр не важен, пробелы по краям не страшны).
- **ID** — главное правило:
  - уникален в пределах листа;
  - **не меняется никогда**: ни при переименовании строки, ни при изменении суммы или даты, ни при сортировке и вставке строк;
  - **не используется повторно**: удалённый ID не отдаётся новой строке;
  - новая строка получает следующий свободный номер;
  - удалить строку = убрать её из плана. Приложение её не удаляет, а помечает «убрано из плана».
- Строка без ID считается сноской: импорт её пропускает и показывает номер строки в проверке.

## Лист «Статьи» — все операции

| Колонка | Обязательно | Значения |
| --- | --- | --- |
| ID | да | буквы + цифры, как сейчас: `S0`, `O13`, `N8`, `D15` |
| Дата | да | дата операции (для плана — ожидаемая) |
| Группа | да | Старт · Доход · Обязательное · Поездки и события · Долги · Жизнь · Буфер |
| Статья | да | название, текст |
| Сумма | да | > 0 |
| Знак | да | `+1` поступление · `-1` списание · `0` перевод между своими счетами или кармашками (баланс не меняет) |
| Статус | да | **факт** — уже прошло по счёту · **план** — ожидается |
| Вид | да | **разовая** · **бюджет недели** · **итог недели** |
| Неделя | для «бюджет недели» и «итог недели» | номер недели бюджета (как в листе «Недели», колонка «№») |
| Счёт | нет | Revolut · Sparkasse · Наличные · Казахстанская карта · пусто, если неизвестно |
| Конверт | нет | ID из листа «Конверты» — трата из конверта (не входит в лимит недели) |
| Долг | нет | ID из листа «Долги» — эта операция погашает долг или получает долг назад |
| Заметка | нет | текст |

Правила:
- **Одна строка — одно состояние.** Ни одной строки, где факт и план смешаны («продукты (факт) и остаток недели» нельзя). Нужны две строки: «итог недели» за прошедшее и «бюджет недели» на оставшееся — или только «бюджет недели» для текущей недели, а траты текущей недели приложение берёт из своих отметок.
- **Бюджет недели** — только со статусом «план». Это план трат недели, а не одно списание: приложение не спрашивает «Списалось?», а после конца недели убирает строку из плана.
- **Итог недели** — только со статусом «факт». Это сумма трат недели целиком: траты из приложения за эту неделю остаются в статистике категорий, но в баланс второй раз не идут.
- **S0 / «Старт»** — начальный остаток, Знак `+1`, Статус «факт», Вид «разовая».
- Когда плановая операция прошла — меняй Статус на «факт», ID не трогай. Так же отвечает приложение на «Пришло? / Списалось?». Если вы с приложением поменяете одну и ту же строку по-разному, импорт покажет конфликт.

Пример:

| ID | Дата | Группа | Статья | Сумма | Знак | Статус | Вид | Неделя | Счёт | Конверт | Долг | Заметка |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| N8 | 04.11.2026 | Жизнь | День перелёта обратно: еда | 33,45 | -1 | факт | разовая | | Revolut | E2 | | Food Village, Duty Free |
| N16 | 16.11.2026 | Жизнь | Неделя 6: у сестры | 25 | -1 | план | бюджет недели | 6 | | | | продукты платит сестра |
| N14 | 02.11.2026 | Жизнь | Неделя 4: у сестры | 68 | -1 | факт | итог недели | 4 | Наличные | | | |
| D2 | 01.12.2026 | Обязательное | Miete | 650 | -1 | план | разовая | | Sparkasse | | | |
| N30 | 30.11.2026 | Долги | Депозит жильцу | 100 | -1 | план | разовая | | Revolut | | L1 | |

## Лист «Недели» — лимиты

Как сейчас: `№` (ID недели, 1, 2, 3…), `Начало` (понедельник), `Конец` (воскресенье), `Где` (текст, необязательно) и шесть колонок лимитов: `Продукты`, `Кофейни и перекусы`, `Выходы и еда вне дома`, `Мелочи`, `Шопинг`, `Доставка` (числа ≥ 0 или пусто). Неделя строго пн–вс; неделя 1 = 12.10–18.10.2026.

## Лист «Конверты» — конверты и цели

| Колонка | Обязательно | Значения |
| --- | --- | --- |
| ID | да | `E1`, `E2`… |
| Название | да | текст |
| Тип | да | **конверт** — деньги отложены на трату («Подарки», «Франкфурт») · **цель** — копим к сумме («Подушка», «Казахстан») |
| Заложено | да | сколько отложено, ≥ 0 |
| Потрачено | нет | формула: `=СУММЕСЛИМН(Статьи!Сумма; Статьи!Конверт; [@ID]; Статьи!Статус; "факт")` |
| Осталось | нет | формула: `=Заложено − Потрачено` |
| Когда | нет | текст («до 20.12», «21.12 — 08.01») |
| Цель | для «цель» | сумма, к которой копим |
| Срок | для «цель» | дата, к которой нужна сумма (можно пусто) |
| Сейчас на счету | нет | только для себя, формулой из «Остатков» — последний остаток этого кармашка: `=СУММЕСЛИМН(Остатки!Остаток; Остатки!Счёт; [@ID]; Остатки!Дата; МАКСЕСЛИ(Остатки!Дата; Остатки!Счёт; [@ID]))` |
| Заметка | нет | текст |

«Потрачено» и «Осталось» импорт не берёт: приложение считает их само по операциям с этим конвертом. Если ваши числа разойдутся с расчётом, проверка покажет расхождение.

«Сейчас на счету» импорт тоже не берёт: единственный источник реального остатка — лист «Остатки». Для цели приложение показывает последнюю строку «Остатков» с её ID; строк нет — «остаток не внесён».

«На руке 50 €» — это не конверт, а правило: перенести в лист «Правила».

Пример:

| ID | Название | Тип | Заложено | Потрачено | Осталось | Когда | Цель | Срок | Сейчас на счету | Заметка |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| E1 | Подарки | конверт | 200 | 80 | 120 | до 20.12 | | | | |
| E5 | Подушка | цель | 0 | 0 | 0 | | 1000 | 31.03.2027 | 390 *(формула)* | Revolut-кармашек |

## Лист «Долги» — новый

| Колонка | Обязательно | Значения |
| --- | --- | --- |
| ID | да | `L1`, `L2`… |
| Кто | да | имя или «Подушка» |
| Направление | да | **я должна** · **мне должны** · **заём из копилки** |
| Сумма | да | > 0, сколько всего |
| Возвращено | нет | число или формула `=СУММЕСЛИМН(Статьи!Сумма; Статьи!Долг; [@ID]; Статьи!Статус; "факт")` |
| Остаток | нет | формула: `=Сумма − Возвращено` |
| Срок | нет | дата или пусто |
| Статус | да | **открыт** · **закрыт** |
| Копилка | для «заём из копилки» | ID цели из «Конвертов», из которой взяли |
| Заметка | нет | текст |

- Депозит жильца — сюда, как «я должна».
- Заём у «Подушки» — как «заём из копилки», в «Копилке» — ID «Подушки» (например, `E5`). Приложение покажет этот заём и в цели «Подушка».

Пример:

| ID | Кто | Направление | Сумма | Возвращено | Остаток | Срок | Статус | Копилка | Заметка |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| L1 | Жилец (депозит) | я должна | 100 | 0 | 100 | 30.11.2026 | открыт | | вернуть при выезде |
| L2 | Подушка | заём из копилки | 150 | 50 | 100 | | открыт | E5 | на Франкфурт |

## Лист «Остатки» — новый

Реальные остатки, независимый факт: что видно в банке или в кошельке на дату. Это единственный источник реальных остатков — и для сверки, и для целей. Приложение сравнивает остатки счетов с расчётным балансом на ту же дату («сходится» или «расхождение X €»); остатки кармашков (ID цели) показывает в целях и в сверку не складывает — они уже внутри своего счёта. Воскресный обзор пишет туда же.

| Колонка | Обязательно | Значения |
| --- | --- | --- |
| Дата | да | дата сверки |
| Счёт | да | Revolut · Sparkasse · Наличные · Казахстанская карта — или ID цели/конверта из «Конвертов» для кармашка |
| Остаток | да | ≥ 0, реальная сумма |

ID не нужен: строку однозначно определяют «Дата» + «Счёт» (одна такая пара — одна строка).

Пример:

| Дата | Счёт | Остаток |
| --- | --- | --- |
| 15.11.2026 | Revolut | 742,10 |
| 15.11.2026 | Sparkasse | 1 120,00 |
| 15.11.2026 | E5 | 390,00 |

## Лист «Правила»

Как сейчас: `№`, `Правило`, `Подробно`. Сюда же «На руке 50 €».

## Лист «Календарь» — необязательный

Если остаётся, импортируется только как заметка-архив «Календарь списаний (архив)». Счета и действия в операции из него больше не переносятся: счёт — колонка «Счёт» в «Статьях», действия — задачи.

## Листы, которые импорт не читает

«Обзор», «Отчёт недели» и любые другие — можно держать для себя.
